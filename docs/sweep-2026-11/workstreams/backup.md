### <a id="sup-27"></a>SUP-27 — The backup size cap counts characters as if they were bytes
*medium · `bugfix` · effort S.* **Where:** `src/storage/backup.ts:368`; `src/storage/backup.ts:369`; `src/storage/backup.ts:383`; `src/storage/backup.ts:385`; `src/storage/storage.ts:240`; `src/storage/storage.ts:529`. **Problem.** MAX_BACKUP_TOTAL_BYTES (2 MB) is compared with JSON.stringify(backup).length, which counts characters. localStorage stores two bytes per character, and the code budgets it at 5 MB (LOCAL_STORAGE_BUDGET_BYTES) while measuring usage as length*2.
